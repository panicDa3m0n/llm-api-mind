# Avatar Authoring Archive

This directory keeps paused Scarlet avatar-authoring sources outside the
frontend public asset tree.

The PSD files are retained through Git LFS as recoverable research evidence.
They are not Product UI runtime assets, are not copied by Vite or Capacitor,
and must not be deployed to the VPS or packaged in the Android application.

Current archived files:

- `psd/Poopoo.psd`: third-party structural reference used by the paused layered
  puppet experiment;
- `psd/rig/scarlet-layered-rig-workspace-v1.psd`;
- `psd/rig/scarlet-layered-rig-workspace-v2.psd`; and
- `psd/work/eye_scarlet_right_upper_lash_liner/v1/eye_scarlet_right_upper_lash_liner-v1-review.psd`.

The active Product UI uses the approved static Scarlet portrait and startup
greeting media documented in `docs/product-ui-prototype.md`.
