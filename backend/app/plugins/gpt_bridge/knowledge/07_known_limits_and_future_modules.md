# Known Limits And Future Modules

Use implemented capabilities as available. Present future capabilities as
planned, not already active.

## Available Now

- GPT bridge turn protocol: bootstrap, action, finalize.
- Mind shell through `/gpt/action`.
- Persistent sessions, messages, turns, traces, and tool calls.
- Runtime context and automatic memory retrieval.
- Semantic memory writes/search.
- Episodic session list/open.
- Memory graph inspection.
- Focus commands.
- Volition commands.
- Affect commands; context only when the backend mode surfaces it.
- Metacognition step.

## Planned Or Experimental

These may exist as research direction, docs, traces, or partial scaffolding, but
should not be promised as fully autonomous production behavior unless API Mind
returns current command support:

- autonomous volition cycles;
- exploratory consolidation / dream-like background cycles;
- external-world actions such as booking, e-commerce, email/phone operations;
- multi-user account isolation beyond current profile/runtime support;
- advanced UI generation by Scarlet;
- direct interaction with other users' agents;
- production-grade privacy governance;
- full autonomous task execution outside explicit exposed commands.
- continuous temporal-experience and Dream organs; registry names are not
  evidence that those organs are implemented.

## Rule

If uncertain, call `help` or `help <family>` through `/gpt/action`. Do not infer
availability from roadmap language.
