## Calibration Run 1 - Rejected

At the initial `0.55` threshold, recall worked but final acceptance did not:

- 35 active memories inspected;
- 20 candidates reached final rerank;
- expected memory rank: 1;
- expected memory score: `0.465327`;
- classification: `near_miss`;
- selected count: 0.

Scarlet therefore did not receive the memory. This established that `0.55`
was not calibrated for the configured reranker and this positive Italian
paraphrase. The threshold was lowered provisionally to `0.40`; no route score
or deterministic semantic weight was added.

## Calibration Run 2 - Technically Selected, Invalid As Model Evidence

At `0.40`, rich `memory.context` selected the expected memory, but the compact
V2 projection excluded it because the historical row lacked
`source_message_id`. MiniMax did not receive the memory id or claim. Scarlet's
incidental mention of mint was therefore rejected as evidence.

This was test-preparation evidence, not a projection defect: V2 intentionally
requires complete, resolvable session/message provenance and must not invent
it.

Zero-Luce prompt put the active reference first in sparse, dense, graph, and
lexical recall, but the reranker score was only `0.089455`; the second candidate

of model-produced relevance only; route-local scores remain non-authoritative.

## Verdict

Initial acceptance passes for this positive/negative pair. The expected memory
was found from the full active set, accepted only by final rerank, delivered to

Italian paraphrases, ambiguous queries, weak positives, negative controls,
candidate-limit stress cases, and provider-failure observations are required.
