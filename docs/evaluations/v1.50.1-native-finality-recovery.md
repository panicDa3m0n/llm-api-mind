# V1.50.1 Native Finality Semantic Recovery

Date: 2026-07-19
Issue: Linear SCA-44
Status: accepted, deployed, and tagged `v1.50.1`

## Objective

Prevent repeated omission of the private native final marker from discarding a
complete corrected MiniMax answer, while preserving the stronger invariant that
progress notes, fragments, empty output, and unjudgeable drafts never become the
canonical assistant response.

## Production Discovery

The protected V1.50.0 image passed database and deployment checks. Focused turn
`turn_a35981d139214ceeb0d135f2732ec8b9` then proved:

- `mem_1bbd0dc1ef4f47e787ec2fa1c521e1d3` was selected with exact session, turn,
  and message provenance;
- the memory reached `scarlet-model-context-v2` and the persisted model request;
- Scarlet executed `memory graph` successfully;
- the original and corrected provider drafts were non-empty and the second was
  a complete natural answer;
- both omitted `<scarlet-final/>`, causing the intended fail-closed HTTP 502.

A separate simple natural request reproduced the same two-miss failure. The
evidence therefore isolates answer-boundary compliance from retrieval, shell,
database, deployment, and provider-empty-response failures.

## Design

The primary path is unchanged: a marked answer is stripped and accepted only
after all semantic obligations pass. The first missing marker still triggers
one correction. On the second miss only, the runtime adds
`answer.final_boundary.semantic_recovery`, a hard semantic requirement that the
draft be complete, standalone, conclusive, and independent of rejected public
text. The existing structured LLM judge evaluates it together with any other
hard semantic obligations.

No answer is rewritten. Judge failure, `fail`/`unknown`, a progress note, or any
other hard failure rejects the turn.

## Acceptance Matrix

| Case | Expected |
| --- | --- |
| Valid private marker | strip marker and persist public text |
| First marker miss | request one bounded correction |
| Complete second draft without marker | LLM finality pass, persist unchanged |
| Second progress note without marker | LLM finality fail, HTTP 502 |
| Validator unavailable | fail closed |
| Empty/thinking-only provider result | existing incomplete-response rejection |
