# V1.32 Shell Organ Audit

Date: 2026-07-13
Status: accepted technical conformance; behavioral maturity remains organ-specific
Database boundary: frozen preliminary DB and disposable copies only

## Objective

Verify every model-facing cognitive-shell family after the memory retrieval
work, compare registry/help/parser/handler/storage behavior, repair concrete
contract drift, and then observe Scarlet using representative organs in
natural MiniMax M3 turns. Production `backend/data/app.db` was not used or
modified by this evaluation.

## Technical Audit

| Family | Fault found | Verified behavior after repair |
|---|---|---|
| `help` | unknown namespaces validated as available; aliases disagreed with execution | all 23 family/namespace aliases agree; every published command validates; unknown help fails explicitly |
| `session` | hidden 500-session ceiling; truncated windows also truncated fallback-summary evidence | deep pagination and exhaustive query work; fallback summary uses the complete transcript |
| `focus` | `hold` recorded a transition but left status `active`; targeted miss looked successful | held status persists; list/search/timeline paginate; targeted miss returns `focus.not_found` |
| `volition` | review scheduling flags were discarded; promote returned endpoint-shaped instructions | scheduling reaches storage; due queue works; promote returns an executable linked `focus set` command |
| `affect` | read filters were ignored; targeted miss looked successful | emotion/mode/status filters, pagination, prototypes, and `affect.not_found` work |
| `mode` | `interactive` could be persisted manually outside a human turn | only `idle` and `scouting` are resumable; interactive remains system-owned |
| `metacognition` | retrospective `turn_scope` and `detail` flags were discarded | both fields reach the reviewer; retrospective and ordinary modes retain one route |
| recovery/aliases | `memory show/get` were advertised but not handled; empty searches reached handlers | aliases execute and empty focus/volition search fails locally with usage guidance |

The volition lifecycle was exercised directly through create, read, search,
update, defer, review, due-list, promote, focus execution, resolve,
impossible, deprecate, and active-list operations. Session pagination was
tested with 505 generated sessions. Affect filters were tested against
multiple distinct states. These tests include success and negative paths.

## Live Scarlet Scenarios

Five independent natural Italian scenarios ran against a disposable copy with
real MiniMax M3. The resulting DB was deleted after evidence extraction.

| Scenario | Starting condition | Scarlet actions | Outcome |
|---|---|---|---|
| Episodic continuity | new session over frozen historical data | session search, memory search, three session opens | reconstructed a three-session historical chain from exact transcripts and clearly separated transcript from missing thinking content |
| Affect inspection | new session with one known curiosity state | `affect read`, `affect prototypes` | reported only the recorded state and distinguished it from legacy mood seed |
| Focus | new session, no active focus | `focus read`, `help focus`, `focus set`, failed then corrected memory write | created the requested foreground constraint and recovered correctly from obsolete memory-write flag names |
| Volition | new session, no open intentions | active/due lists, help, scheduled create | created a self-owned long-horizon intention with future review without presenting it as a user task or autonomous execution |
| Metacognition | new session with prior test sessions available | three session opens, session list, critic step | explicitly rejected the unsupported inference that several successful calls prove general shell reliability |

Observed total: 20 successful shell calls and one recoverable malformed
memory-write call. All five turns completed with HTTP 200 and persisted their
normal trace/event sequences in the disposable DB.

## Interpretation And Limits

The shell is now a coherent executable contract across its current command
families. This establishes implementation conformance, pagination truth,
recoverable errors, and representative real-model use. It does not establish
that Scarlet will autonomously choose every command when useful, that affect
is longitudinally calibrated, that focus is maintained without prompting, or
that volition has an autonomous execution cycle. Those are behavioral and
runtime-integration questions, not unresolved shell-transport bugs.

## Production Confirmation

production preflight. Public GPT Actions exercised all eight current shell
families in one non-destructive turn, native MiniMax completed a second turn,
and production retrieval traces showed the OpenRouter final reranker completed
successfully. Post-smoke integrity remained `ok` with the memory count
unchanged at 294.
