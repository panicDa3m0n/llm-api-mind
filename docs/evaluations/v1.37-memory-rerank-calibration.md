# V1.37 Memory Rerank Calibration

Date: 2026-07-18
Status: accepted for SCA-3
Experiment: `EXP-0065`

## Objective

Calibrate the final memory-level reranker against frozen real references and
real Scarlet turns without allowing sparse, dense, graph, or lexical scores to
decide relevance. The gate measures candidate coverage, final acceptance,
sourceable V2 delivery, negative separation, KG participation, latency, and
semantic answer use.

## Accepted Policy

V1.37 uses `memory_level_rerank_adaptive_floor_v2`:

```txt
effective acceptance floor = max(
  RETRIEVAL_HYBRID_MIN_RERANK_SCORE,
  best reranker score for this query * RETRIEVAL_HYBRID_RELATIVE_RERANK_FLOOR
)
```

Calibrated defaults are `0.004` absolute and `0.01` relative. Both values are
applied only to scores produced by the final reranker. Recall-route scores,
stored confidence, salience, and legacy weighted fusion remain non-authoritative.
Active mode remains fail-closed when configuration or the provider is
unavailable.

The absolute floor is above every observed unrelated-negative result. The
relative floor follows the scale of the current query: it filters tangential
low-scoring memories when one candidate is very strong while retaining several
moderately scored memories when the user question genuinely needs several
facts. Trace status now records the minimum floor, relative floor, best score,
effective threshold, and reranker latency.

Artifact:
`backend/app/evals/runs/20260718_104346_memory-rerank-calibration-v1.json`
(ignored runtime evidence).

Three independent real MiniMax M3 turns ran on fresh disposable copies:

1. Evening beverage paraphrase: Scarlet received the mint and caffeine hooks
   and recommended mint tea as the user's established calming, caffeine-free
   preference. Technical and semantic result accepted.
2. Body disambiguation: Scarlet received the architecture memories and clearly
   distinguished memory/database architecture from a merely robotic body.
   Technical and semantic result accepted.
3. Jazz/cooking negative: `memories.relevant` was empty; Scarlet gave general
   music advice without claiming personal recall. Technical and semantic
   result accepted.

Observed full-turn latencies were 12.5-14.8 seconds. Rerank itself remained
below one second, so most live latency belongs to normal model generation
rather than memory arbitration.

## Retry Boundary

No retrieval-provider failure occurred in the final 22 frozen decisions or
three final live turns. Runtime active retrieval therefore remains
fail-closed and does not gain an unproven retry loop in SCA-3. The separate
maintenance retry/resume gap concerns background summary/proposal jobs and
remains roadmap work; this calibration neither exercises nor closes it.

## Verdict

SCA-3 is accepted. The final reranker remains the sole relevance authority,
the fixed-floor false negative is removed, unrelated negatives remain closed,
KG recall is observable, V2 provenance is checked, and real Scarlet uses the
selected evidence correctly. The eleven-case runner is reusable for future
reranker model or threshold changes, but its small real dataset is not proof of
universal calibration. Provider drift and larger-memory candidate pressure
remain longitudinal monitoring concerns.
