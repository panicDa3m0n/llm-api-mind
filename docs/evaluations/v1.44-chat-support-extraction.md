# V1.44 Chat Support Extraction

Date: 2026-07-18
Issue: Linear SCA-34
Branch: `feature/sca-34-chat-support-extraction`
Status: implementation and bounded direct verification complete

## Scope

This organization-only slice moves provider-history transformations,
response/event serialization, and context-accounting helpers out of
`backend/app/api/chat.py`. Native turn orchestration, streaming semantics,
answer obligations, provider protocol, compaction, context routing, prompts,
database state, and GPT behavior remain unchanged.

## Structural Result

- `chat_provider_history.py` owns canonical provider-history transforms.
- `chat_serialization.py` owns public response models and event projections.
- `chat_accounting.py` owns accounting trace persistence and request stats.
- `chat.py` re-exports its public response models and remains the router facade.
- the GPT Actions router imports shared owners instead of private chat helpers.
- `chat.py` changed from 2,641 to 2,197 lines.

Pre/post OpenAPI documents are exactly equal after JSON serialization: 26
paths and 29 schemas on both revisions. No endpoint or schema changed.

## Direct Native Probe

The probe used an ignored disposable copy, native MiniMax configuration, no
maintenance workers, and the normal large output budget. It did not mutate the
laboratory or production database.

Session: `ses_2a4fcb91e6f44ed6a0be6273b4fa027b`.

Turn one asked for a natural one-sentence greeting. Scarlet responded:

> Ciao, Test nome! Che bello risentirti — dimmi, cosa ti porto oggi?

Direct judgment: one sentence, warm and coherent, with no unnecessary tool
call. `cosa ti porto oggi?` is slightly service-like but is ordinary model
style variance and unrelated to the extraction.

Turn two asked, in one sentence, what Scarlet had said made her happy. The
provider request used `session.provider_history_json` and contained the prior
user message, complete assistant content, and current user message. Scarlet
responded:

> Ho detto "Che bello risentirti" — il piacere di rivederti dopo un po' di tempo.

Direct judgment: the quoted phrase is exact and answers the continuity test.
The temporal gloss is a plausible reading of `risentirti`, not evidence of
lost provider history. One answer-obligation correction occurred, then the
turn completed normally.

## Invalid And Residual Evidence

A first 1,024-output-token attempt was rejected as an evaluator setup error:
it did not represent native Scarlet's configured budget and cannot support a
behavioral conclusion.

A separate correctly budgeted probe exposed BUG-0091: after a malformed memory
write failed and a corrected retry succeeded, answer obligations retained only
the failure evidence and rejected truthful final drafts. This is a real
pre-existing shared-runtime bug tracked in SCA-42, not an SCA-34 regression.

## Acceptance

SCA-34 is admissible because objective contracts are equal or better and the
direct same-session behavior confirms canonical provider continuity. No result
depends only on an aggregate score; the actual actions, traces, and responses
were inspected and classified.
