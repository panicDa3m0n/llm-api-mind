## Scope

This organization-only slice moves automatic memory candidate collection,
ranking, classification, final rerank projection, conflict evidence, and
negative evidence out of `app.mind.context`. Runtime block assembly, V2
projection policy, traces, activity recording, shell behavior, ranking policy,
provider behavior, public APIs, and database schema remain unchanged.

## Structural Result

- `context_retrieval.py` is the typed owner of automatic retrieval.
- `context.py` remains the stable runtime-context facade and decreases from
  1,809 to 1,161 lines.
- the retrieval result explicitly carries candidate scores, selected,
  near-miss, excluded, conflicts, negative evidence, and rerank diagnostics;
- trace and model-packet assembly continue outside retrieval; and
- mypy now guards 15 high-value modules.

## Direct Model-Facing Probe

The natural prompt asked Scarlet which structure to follow when mentioning the
Protocollo Zero-Luce. The first disposable run selected the active memory in
rich `memory.context`, yet Scarlet answered that she had no memory. Direct
trace inspection showed that the actual V2 `model.context.memories` was empty
and the provider request contained no Zero-Luce text.

This was not a retrieval regression or an LLM evaluation error. The selected
frozen memory had source session and turn ids but no source message id. The V2
projector correctly rejected an incomplete hook. The source turn contains one
exact user message, and the existing provenance maintainer classified it as
`repairable_single_user_message`.

On the disposable copy only, exact repair populated
`msg_a3adf09c456246be92f91c774c9c25d0`. The repeated natural request then
delivered the memory to MiniMax without a manual tool call. Scarlet returned
the four required ordered sections: Contesto, Evidenza, Rischio, and Prossima
azione.

Direct judgment: the repaired run is behaviorally correct. It uses the
relevant automatic memory, preserves the protocol's complete structure, and
does not invent unsupported additions. The unrepaired run is also informative:
its answer follows the evidence actually delivered to the model and exposes an
evaluation-fixture gap rather than poor model reasoning.
