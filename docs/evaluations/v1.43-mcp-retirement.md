# V1.43 MCP Retirement

Date: 2026-07-18
Issue: SCA-22
Branch: `feature/sca-22-remove-deprecated-mcp`
Type: Implementazione
Target: V1.43.0
Status: local implementation verified; remote rollout pending

## Objective

Remove the abandoned MCP/App transport without changing Scarlet's cognitive
runtime, GPT Actions lifecycle, native shell contract, internal maintenance
routes, or canonical historical data.

## Scope

- delete application `GET/POST /mcp` routing and JSON-RPC helpers;
- delete MCP lifecycle/cognitive tool descriptors and connector prompt;
- remove query-string bridge-key authentication;
- remove the dedicated production Nginx `/mcp` proxy location;
- keep `/gpt/bootstrap`, `/gpt/action`, and `/gpt/finalize` unchanged;
- keep native `mind_shell(command, intent)` and internal `/mind/*` dispatch;
- preserve all historical MCP-originated database records.

Credential rotation is not performed silently in this slice because the same
key authenticates the active GPT Actions configuration. Rotation requires a
coordinated external dashboard update.

## Starting Evidence

The frozen preliminary gate passed 9/9 in:

```txt
20260718_162922_preliminary-regression-v1
```

Focused pre-change GPT bridge and shell tests passed 30 tests. Read-only
production inspection established:

- 34 historical sessions use `source=mcp_bridge`;
- recent requests reached the dedicated Nginx `/mcp` proxy from an external
  `openai-mcp` client;
- the backend has no internal worker that depends on that route;
- query-string credentials appeared at the proxy access-log boundary; and
- the three GPT Actions are active and remain the target integration.

This means retirement is an intentional external contract removal, not dead
code cleanup. Historical rows are evidence and must remain unchanged.

## Implementation

The application router now contains only the three GPT Actions. Production
authentication accepts only `Authorization: Bearer` and
`X-GPT-Bridge-Key`. The Actions OpenAPI schema contains exactly the three GPT
paths. Current operational docs no longer instruct users to configure an MCP
connector; chronological ADR, experiment, changelog, and activity records keep
their historical claims.

## Residual Risk

The active bridge secret should be rotated because prior connector URLs may
have copied it into logs. Rotation must be coordinated with the Custom GPT
Action secret to avoid an avoidable production outage. Historical MCP sessions
will continue to carry their original source label by design.
